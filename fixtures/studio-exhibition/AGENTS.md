# Exhibition demo project

This is a fictional exhibition used to test collaborative software creation.
All booth names and descriptions in `booths.json` are synthetic.

- Implement the requested visitor experience in `index.html`, `styles.css`, and `app.js`. Read the existing booth data; preserve `server.mjs`, `booths.json`, and these instructions.
- Use plain HTML, CSS, and JavaScript. No build step, dependencies, external services, accounts, trackers, or network assets are needed.
- Prioritize an intentional visual hierarchy, legible Japanese, keyboard access, touch targets at least 44 pixels, and a useful 320-pixel layout.
- Keep acceptance conditions visible in the resulting behavior. If a condition changes, implement the latest explicit correction while preserving the other conditions.
- Check JavaScript syntax and the edited files. The host starts the preview and performs real browser checks after your turn.
- Do not commit, deploy, create agents, or change files outside this task workspace.
