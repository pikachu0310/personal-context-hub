# 共有タスクの履歴

共有タスクを開くと、実行者のタスク画面と同じ会話・行動ログ・詳細情報を表示する。
閲覧にはEngineで承認された端末とプロジェクトへの参加が必要。Codexログイン、
実行許可、作業フォルダーの登録は不要。操作と承認の権限は変わらず、
ほかの端末の承認要求は閲覧だけできる。

## 共有内容

依頼、回答、過去の実行履歴、作業メモ、計画、追加指示、コマンドと出力、
変更ファイル、未コミット差分、モデル・実行設定、作業フォルダー・ブランチ、
実行時に渡したソース（担当者のユーザー情報を含む）、承認待ちの内容を共有する。
認証情報のマスクと既存のログ上限は適用する。行動ログは最大300件・256,000文字、
本文・出力は各16,000文字、差分は256,000文字で、省略状態も表示する。
削除済みや当初から記録されていないログは復元しない。

通常のEngineタスクと、Engineに登録済みのローカル共有タスクが対象。
共有していないローカルタスクは同期しない。Discordへの投稿は従来の要約のまま。

## 保存と再接続

実行Clientは詳細の変更を最大2.5秒間隔で同期する。実行開始・終了時と
再接続時にも同期する。環境と差分は実行中5秒間隔および再読み込み時に取得する。
Gitの取得に失敗しても会話の同期は続く。

EngineのSQLiteに独立したtask-detailレコードを保存する。実行PCが
オフラインでも最終同期時点の情報を閲覧でき、画面に接続状態と同期時刻を表示する。
一覧、通常の結果通知、Botへのイベントには詳細を含めない。

認証済みWebSocketのtaskDetailVersion 1とworkspace.requestを使用する。
task.detail.targetで担当端末・実行ID・revisionを確認してから、task.detail.syncで
連番付きのスナップショットを128 KiBのバイト列に分割し、base64で送る。
同じ連番の再送は冪等で、全チャンクとSHA-256を検証してから保存を切り替える。
旧接続世代、別担当、別revisionからの書き込みは受理しない。

閲覧はtask.detail.readの分割取得、再読み込みはtask.detail.refreshで行う。
各要求で現在のプロジェクト参加権限を確認する。タスク削除時は保存済みの詳細も削除する。
権限を失った端末には以後の詳細を返さず、閲覧画面のキャッシュを破棄する。

## 更新

Engineを先に更新し、実行Clientと閲覧Clientを更新する。更新した実行Clientは、
既存の完了タスクについても手元に残る履歴を同期する。
旧Engineまたは詳細未同期のタスクでは、保存済みの依頼・回答・過去の実行履歴を表示する。
未同期・接続失敗・ログの省略は空の履歴と区別して表示する。
