# アプリ・Engine・Discordの接続

## 参加者の操作

- 左メニューの「このPCで新しいタスク」は未接続でも利用できます。Gitリポジトリ、ログイン済みのCodex・Claude、モデル、推論エフォート、進め方と実行権限を選びます。
- プロジェクトメニューの「このPCでタスクを開始」では共有先を選択済みにします。「新しいタスク」はEngineが実行先を割り当てる依頼です。
- プロジェクトの入力欄で保存したエージェント・モデル・エフォート・Auto/Manualは、Engineへの新規依頼に含めて実行先へ渡します。対応しない旧Clientや、未ログインのエージェントには割り当てません。
- 実行中は入力欄から追加指示・停止を送れます。別PCのタスクも参加権限と既存のタスク操作規則に従います。追加権限の承認は実行PCで行います。
- このPCのタスクは停止を確認後、入力欄の実行権限を変更して追加指示で再開できます。依頼元が指定した制限は保持します。実行許可とAuto/Manualは別設定です。
- プロジェクトの「相談・共有（Issueなし）」と、タスク画面の「チームとの共有会話」から会話できます。投稿だけではタスクを作成・再開しません。相談欄の「タスクにする」で明示的に依頼にします。

## 会話とDiscord

会話の保存先はEngineです。アプリは約5秒、Discordは約10秒で反映します。Discord連携を設定したプロジェクトには相談用スレッドも用意します。Agentの実行ログ全体ではなく、共有会話への投稿がDiscordへ送られます。

Discordの通常投稿は会話です。実行への指示は `指示: 内容`、停止は `停止`、Engine割当タスクの終了後の続きは `再開: 内容` です。ローカル起動タスクの再実行は作成元アプリで行います。投稿から権限を変更したり、Manualの実装開始承認を代行したりしません。

同じGuild・issueフォーラムで選択したプロジェクトは、既定プロジェクトを切り替えても同期を継続します。Engineに保存したタスクとスレッドの組み合わせを照合し、別のGuild・フォーラムへの切り替えは引き継ぎません。

作成・送信結果が不明な場合は、マーカーを照合し、未確認のまま再投稿しません。管理画面のDiscord設定 →「issueフォーラムの同期・復旧」からエラーを確認できます。既存スレッドIDでの復旧は同じBotのタスクマーカーを検証します。「新しいスレッドを作り直す」は管理者の明示操作で、旧スレッドは削除しません。

## 配布と更新

Discord設定の詳細欄にWindows・Apple Silicon Mac・Intel Macの配布URLを設定します。`/ido connect` の案内からダウンロード、アプリ起動、Engineへの接続、個人のエージェントへのログイン、プロジェクト参加と実行許可へ進みます。

ユーザー設定から「更新を確認」「配布ページを開く」を利用できます。更新確認はこのリポジトリの公開Releaseだけを読み、認証情報は送りません。更新版はタスクを停止して上書きインストールします。自動ダウンロード・自動インストールは行いません。

インストーラー生成は既存のDesktop installers workflowを利用します。Release公開・配布URL設定・Windows署名・Mac署名とnotarizationは配布担当の作業です。URL未設定の場合は「配布準備中」と表示します。

## 統合する側の契約

- `taskOptionsVersion: 1`: Taskの `agent`, `model`, `reasoningEffort`, `progressMode` を保持して実行します。Claudeの割当は認証状態とプロジェクトGrantの対応エージェントも検証します。
- `conversationVersion: 1`: 認証済みworkspace操作 `project.conversation` / `task.conversation` と、board toolの `scope: project`。参加資格は毎回Engineで検証します。
- `task.control`: task ID・revision・request IDで追加指示と停止を送ります。`task.access-reset` は終了したタスクの実行端末に限定し、明示された実行ポリシーを保持します。
- 会話は既存のSQLite `task-board` に保存します。相談用レコードの `discussion-<projectId>` は実行キューには登録しません。Discordの転送済みカーソルはフォーラム単位で保存します。

より詳しい境界は[タスク掲示板](task-board.md)、[ローカルタスク共有](local-task-discord-sharing.md)、[デスクトップ配布](main2-desktop-forum.md)を参照してください。
