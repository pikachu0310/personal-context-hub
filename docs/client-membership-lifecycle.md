# プロジェクト・タスクの退出と削除

Clientのプロジェクトメニューから「退出」できます。配下のタスクへの参加も解除し、プロジェクトとタスク・議事録を一覧から隠します。共有データとローカルGitフォルダは保持します。自分のClientで実行中・中断中・停止確認待ちのタスクがある場合は、先に停止または完了してください。

ownerは「ownerを変更」で既存の参加者へ権限を移譲してから退出します。候補がいない場合は先に参加者を招待してください。参加者はClientから、Engine管理者はダッシュボードのプロジェクト詳細から招待URLをコピーできます。自主退出した参加者は有効な招待URLで再参加できます。タスクへの参加状態と実行許可は自動で復元しません。デフォルトプロジェクトの退出状態も再接続後に維持します。

タスクのメニューには「退出」または「参加する」と、権限がある場合の「削除」を表示します。タスクの退出で変わるのは参加アイコンだけです。タスクの閲覧・操作権限・実行は継続し、最後の人間が退出してもタスクを保持します。再参加は明示的に「参加する」で行います。

タスクの完全削除は作成者・プロジェクトowner・Engine管理者だけが実行できます。Clientの通常削除では、実行中・中断中・停止確認待ちのタスクを削除できません。停止確認が届かない場合などは、Engine管理者が管理ダッシュボード（Engineの `/dashboard/`）で対象タスクの行を開き、「タスクを強制削除」を実行できます。確認モーダルはキャンセルを初期選択にします。削除すると全ユーザーからタスク、指示履歴、結果、参加情報、プレビューとIDOが保持するタスクのAIコンテキストを除去します。元の共有会話・議事録、Gitフォルダ、外部サービスに投稿済みの内容は残ります。

プロジェクトの完全削除はEngine管理者がダッシュボードのプロジェクト詳細から行います。確認画面で対象名を入力すると、実行中等のタスクがある場合も含め、配下のタスク・議事録・所属・招待・AIコンテキストを削除できます。デフォルトプロジェクトは削除できません。強制削除と端末への反映については[管理者による完全削除](ido-dashboard.md#管理者による完全削除)を参照してください。

## 同期と復旧

- 新規にDiscordの発言からidobotが切り出すタスクは、割当前はidobotのみ、割当後は実行者とidobotを参加者にします。元発言者は出典として保持し、参加者には自動追加しません。Discord経由の追加指示・再実行はidobotからの指示として表示し、停止操作も発言者を自動参加させません。Clientからの参加・追加指示は従来どおりです。対象タスクに`participantPolicy: "execution"`を保存し、既存タスクの参加者や過去の発言表示は変更しません。認可・監査・再送判定には実際の操作元IDを使います。
- タスク参加状態を永続化し、旧タスクの推定参加者はEngine起動時に一度だけ取り込みます。以後の明示的な退出は、担当割当や状態報告で上書きしません。idobotは人間の参加状態と分離しています。
- 操作確定時に権限、対象の版、実行状態を再確認します。状態が変わっていた場合はキャンセルして更新後にやり直してください。
- Engineは本文を含まない削除記録と再送防止記録を保持します。古い実行報告や同じ要求の再送でタスクを復活させません。
- 削除を含むプロジェクトのモデルセッションと生成途中の応答を破棄し、存続する会話とタスクからコンテキストを再構築します。処理途中だった入力は不確定状態として残し、自動で副作用を再送しません。
- タスクに関連付けられた生成文を削除します。対応の分からない旧生成文は共有履歴として残しますが、再構築するAIコンテキストには含めません。
- Clientは再接続時、実行履歴の報告より先に削除通知を処理します。管理対象のタスク履歴、モデルログとモデル索引の対象行を整理し、Gitフォルダは残します。
- ダッシュボードはEngine側の削除完了とClientの同期待ちを区別して表示します。オフラインClientと削除同期に未対応の旧Clientは同期待ちのままです。旧Clientは更新して再接続してください。

## 検証

`npm run verify:ido`で型チェック・ビルド・テストを実行します。`npm run build:ido`後の`npm run smoke:membership`は一時的なEngineと2台のClientを使い、アイコン同期・退出・owner移譲・キャンセル・再起動・再参加・オフライン削除同期・ダッシュボード削除を実ブラウザーで確認します。外部アカウントやモデルへの接続、外部投稿は行いません。

`npm run build:common-ui`後の`npm run smoke:task-participants`は、合成EngineデータをClientの実コンポーネントに渡し、Discord由来タスクの割当前後・追加指示・明示的な参加、アバターと同一アカウントの集約をブラウザーで確認します。Discord由来の判定にはEngineが渡す`sourcePluginId`を使うため、UUIDやアカウント連携済みの発言者も対象です。入力経路は操作履歴にも保存し、直接Clientや管理画面から行った操作と区別します。
